## Lez 02 - Git branch & collaboration

Per svolgere l'esercitazione su git:

    1. Ho eseguito il First Commit sul main branch contenente il README;
    2. Ho creato il branch "branch_test" e ho modificato il README;
    3. Ho eseguito una push dei branch creati;
    4. Ho fatto modificare il README del main branch da un collega;
    5. Ho eseguito una pull per recuperare le modifiche introdotte in 4;
    6. Ho eseguito il merging dei due branch risolvendo il conflitto sulle modifiche al README.
